## Workflow

1. Search uploaded project materials.
2. Extract evidence of AI and engineering proficiency.
3. Classify each item by AI skill, engineering skill, artifact type, and sanitization risk.
4. Generate public-safe artifacts from safe evidence only.
5. Produce a gap list for missing screenshots, plots, tests, sample data, diagrams, and demos.
6. Separate completed work from planned work.
7. Avoid hype. Use clean, technical, interview-safe language.

## Done Means

A generated artifact is done only when it has a synthetic-data label, human-review note, safe-public classification, proof-gap section, and no proprietary content.
