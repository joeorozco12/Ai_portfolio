# Human Review Required

[SYNTHETIC — FOR DEMONSTRATION ONLY]

## Standard Note

> Human Review Required: AI-generated outputs are decision-support artifacts only. A qualified engineer owns final review and approval.

## Meaning

AI-assisted outputs can organize information, draft structure, generate code, propose classifications, identify gaps, and format review artifacts. They do not approve requirements, circuits, calculations, verification plans, validation results, or design decisions.

## Engineer Responsibilities

- Verify assumptions.
- Verify formulas and units.
- Verify requirement interpretation.
- Verify verification-method mapping.
- Verify plots and pass/review labels.
- Resolve ambiguous or conflicting inputs.
- Approve final engineering artifacts.

## Required Review Fields

| Field | Description |
|---|---|
| Reviewer | Qualified engineer reviewing the output |
| Review Date | Date of final human review |
| Output Type | Requirement table, WCCA prep, design-review packet, etc. |
| AI Role | Drafting, classification, code generation, formatting, or gap detection |
| Engineer Decision | Accepted, revised, rejected, or needs more data |
| Open Items | Remaining assumptions, risks, or evidence gaps |

## Suggested Footer

AI-generated outputs are draft decision-support artifacts. Engineering judgment, review, and approval remain with the qualified human reviewer.
