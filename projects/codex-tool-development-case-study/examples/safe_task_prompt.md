## Purpose

## Example Prompt

```text
Task only.
Work only inside the approved project folder.
Do not edit homepage files or unrelated project folders.

Create a synthetic automotive lighting workflow artifact that organizes draft requirements, assumptions, risks, validation gaps, and human-review controls.

Use only synthetic or sanitized examples.
Do not use proprietary company, customer, supplier, schematic, requirement, part number, program, validation, cost, BOM, harness, ticket, or internal document data.
Do not claim AI performs final engineering approval.

Return:
- files created
- key sections added
- validation performed
- remaining gaps
```

## Why This Is Safe

- It defines the allowed folder before work begins.
- It protects unrelated files.
- It bans proprietary data categories.
- It requires synthetic or sanitized examples.
- It keeps final approval with engineers.

## Human Review Controls
